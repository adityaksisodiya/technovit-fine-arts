# /src/components/

Reusable UI components for the TechnoVIT Photo Gallery.

Subdirectories (created in later phases):
- `ui/` — generic UI primitives (buttons, inputs, modals, loaders)
- `gallery/` — gallery-specific components (masonry grid, photo card, lightbox)
- `upload/` — upload form components (drag-drop, progress)
- `admin/` — admin panel components
- `layout/` — header, footer, navigation
